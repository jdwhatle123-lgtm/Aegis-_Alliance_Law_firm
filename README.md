## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Web server (for full functionality) or file system access
- Text editor or IDE for customization

### Local Development Setup

1. **Clone or Download** the project files
2. **Open in Browser:** Navigate to `website/index.html`
3. **For Development:** Use a local web server for full functionality
   ```bash
   # Using Python 3
   cd "Aegis & Alliance Law Firm/website"
   python -m http.server 8000
   
   # Using Node.js (http-server)
   cd "Aegis & Alliance Law Firm/website"
   npx http-server -p 8000
   
   # Access via http://localhost:8000
   ```
